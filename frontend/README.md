# Еліас Online — фронтенд

React (Vite) додаток, під'єднаний до бекенду (`../backend`): реєстрація/вхід
і лобі йдуть через реальний API + Socket.io. Сама гра (таймер, слова,
рахунок) поки клієнтська — бекенд для неї ще не готовий.

## Запуск

```bash
npm install
cp .env.example .env   # VITE_API_URL — адреса бекенду, за замовчуванням localhost:4000
npm run dev
```

Відкриється на http://localhost:5173. Бекенд (`../backend`) має бути
запущений окремо (`npm run dev` там), інакше запити до `/api/*` не
пройдуть — простіше запускати обидва разом з кореня монорепо: `npm run dev`.

## Що реалізовано (мок)

- Лендінг з поясненням правил
- Реєстрація / вхід (без реальної перевірки)
- Меню: одиночна гра, гра в парах, командна гра
- Лобі капітана: додавання гравців за ID, розподіл по командах
- Ігровий екран: таймер, картка слова, "Вгадав" / "Скіп", рахунок
- Екран результатів

## Наступні кроки до реального онлайн-мультиплеєра

1. **Бекенд**: Node.js + Express
2. **База даних**: MongoDB Atlas
   - `users`: `{ _id, name, passwordHash, createdAt }`
   - `lobbies`: `{ code, captainId, players[], teamA[], teamB[], status }`
   - `games`: `{ lobbyCode, words[], scores, round, history }`
3. **Реалтайм**: Socket.io — щоб лобі, таймер і поточне слово синхронізувались
   в усіх гравців одночасно, а не жили лише в браузері капітана
4. **Auth**: JWT (access/refresh токени) або сесії, паролі — bcrypt
5. **Деплой**:
   - Бекенд: Render або Railway
   - Фронтенд: Vercel
   - БД: MongoDB Atlas (free tier достатньо для старту)

Готовий продовжити з серверною частиною (Express + Socket.io + MongoDB) —
просто скажи.
